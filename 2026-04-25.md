#### 回溯算法实践——N皇后问题
- 前置技巧：
	- 一行只能放一个皇后，`board[i][0..j]`都不能再放，即只做「不同行」验证
	- 对角线的验证：皇后只从上往下逐层放置，下方还没放，只需检查「左上」`i--;j--`和「右上」`i--;j++`
	- String字符串与char数组的相互转换 String s=new String(charArr)<==>char`[]` charArr=s.toCharArray();
- 核心代码：
- ```java
  class Solution {
    List<List<String>> result=new ArrayList<>();
    public List<List<String>> solveNQueens(int n) {
        //初始化结果列表
        List<String> board = new ArrayList<>();
        //初始化棋盘 n*n
        for (int i = 0; i < n; i++) {
            board.add(".".repeat(n));
        }
        backTrack(0, board);

        return result;
    }

    public void backTrack(int index, List<String> board) {
        //基准条件
        if (index == board.size()){
            result.add(new ArrayList<>(board));
            return;
        }


        //节点扇出个数
        int n = board.get(index).length();
        for (int i = 0; i < n; i++) {
            if (!isValid(index, i, board)) {
                continue;
            }
            //新增路径
            char[] newRow = board.get(index).toCharArray();
            newRow[i] = 'Q';
            board.set(index, new String(newRow));

            //子节点递归
            backTrack(index + 1, board);

            //撤销路径
            newRow[i] = '.';
            board.set(index, new String(newRow));

        }
    }

    public boolean isValid(int r, int c, List<String> board) {
        int n = board.size();
        for (int i = 0; i < r; i++) {
            if (board.get(i).charAt(c) == 'Q')
                return false;
        }

        //左上角判断
        for (int i = r - 1, j = c - 1; j >= 0 && i >= 0; i--, j--) {
            if (board.get(i).charAt(j) == 'Q')
                return false;
        }

        //右上角判断
        for (int i = r - 1, j = c + 1; j < n && i >= 0; j++, i--) {
            if (board.get(i).charAt(j) == 'Q')
                return false;
        }

        return true;
    }
}
  ```
