## Scope

Use this note for daily events, feelings, realizations, changes, and early
ideas. Do not turn a quick capture into a project plan or a formal procedure
unless the user asks or the idea is clearly becoming reusable.

## Folder Map

- Daily records: `Journal/YYYY-MM-DD.md`
- Durable ideas and learning: `Insights/{descriptive title}.md`
- Domain rules: `Instructions/`

## Capture Workflow

1. Search the current date note before creating it.
2. Append the new event or thought to the daily note when it belongs there.
3. Include `[date]` and at least one meaningful observation such as `[event]`, `[idea]`, `[learning]`, or `[change]`.
4. Link any mentioned Project, Procedure, or Insight.
5. Promote an idea to `Insights/` only when it should be reused beyond the day; keep the journal as context, not a duplicate copy.

## Naming

Use `YYYY-MM-DD` for daily notes. Use a descriptive title for durable Insights.

## Observations

- [convention] Capture is intentionally low friction because the user expects more than five idea records per week.
- [convention] Journals are the connective tissue of the graph and may link to every other domain.
