# 2026-09-07

今天在阅读 AI 应用开发招聘信息时，看到“生产级 Agent”要求覆盖复杂任务规划与执行、记忆与状态、评测、监控、异常和成本管理。对照自己的实践，我发现原有能力主要集中在 Prompt / 上下文工程、RAG 知识检索和 Tool Calling，生产级 Agent 相关能力仍然缺少系统理解。

今天进一步了解了 LangChain、LangGraph 和 LangSmith，也把它们从“不同框架”重新理解为 AI 应用不同阶段的实施方案：LangChain 适合快速构建 MVP 和固定链路，LangGraph 适合复杂任务编排、状态持久化、人机协同和多 Agent，LangSmith 负责上线后的追踪、评测和监控。

这个理解变化直接连接到 [[AI零代码应用生成平台]] 的下一阶段建设。
