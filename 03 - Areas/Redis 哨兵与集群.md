### **主从复制**

- 定义：数据同步机制
    
- 价值：主节点读写，从节点同步和读操作，解决单点故障
    
- 全量复制：通过 RDB 定时同步给从节点
    
- 增量复制：通过缓冲区记录同步期间的写操作，复制完成后同步给从节点；设置缓冲区的复制偏移量避免每次全量同步以及从节点宕机后回溯复制进度
    

### **哨兵**

- 定义：监控 Redis 内部状态和实现节点切换的进程（同套 Redis 代码，不同启动参数）
    
- 价值：动态故障转移
    
- 监控：获取主节点 + 从节点数据，定时 ping 检查连通性
    
- 转移：优先选举配置优先级高、复制偏移量大的从节点作为备选主节点；修改主节点地址，故障节点降级为从节点
    

### **哨兵机制**

- 定义：多个哨兵集群（1 主 2 从 3 哨兵）
    
- 价值：解决单点哨兵故障 + Redis 状态误判
    
- 流程：多哨兵间互相通信 → 单个哨兵认为 Redis 下线（主观下线）→ 向其他哨兵确认 → 超半数哨兵认为下线（客观下线）→ 开始故障转移
