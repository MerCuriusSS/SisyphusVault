# 小说粗大纲（卷维度）到单章内容的中间产出物

当你已经确定了「卷维度的粗大纲」和「核心人设」，要落地到每一章具体写什么，中间需要逐步拆解、细化，形成层层递进的内容框架，既保证不偏离核心设定，又能让单章有明确的目标和细节。以下是必须产出的关键内容，按逻辑顺序排列，可直接对应AI创作的需求，避免写崩人设、偏离主线：

## 一、卷级细化大纲（承上启下的核心环节）

卷维度的粗大纲通常只明确「这一卷的核心冲突、起止节点、最终达成的剧情成果」（比如“第一卷：主角初入江湖，结识伙伴，破解入门危机，最终加入门派”），但缺乏具体的剧情脉络。这一步需要把粗大纲拆解成「卷内关键剧情节点」，相当于给每一卷画好“剧情骨架”，是衔接粗大纲和单章的核心桥梁。

具体产出内容：

- 卷的核心目标（明确这一卷要完成什么：是人物成长、冲突爆发、伏笔回收，还是场景转换？比如“核心目标：主角从懵懂新手，成长为能独立应对江湖小危机的入门弟子，建立2-3个核心人际关系”）。
    
- 卷内关键剧情节点（按时间/逻辑顺序排列，每个节点对应一个“小剧情单元”，通常1-3个节点对应后续1-5章内容，避免太零散）。例如：节点1：主角离开家乡，途中遭遇第一次危机（被山贼拦截）；节点2：偶遇第一个伙伴，两人临时结盟；节点3：抵达门派，参加入门考核，遭遇竞争对手刁难；节点4：考核通过，正式入门，埋下门派内部矛盾的伏笔。
    
- 卷的起承转合（明确每一部分的剧情节奏）：① 起（开篇引入：主角为什么进入这一卷的场景/剧情，比如“主角为寻亲人，被迫离开家乡，踏入江湖”）；② 承（剧情推进：通过关键节点，逐步铺陈冲突、塑造关系，比如“途中遇袭、结识伙伴，展现主角的善良和伙伴的谨慎”）；③ 转（核心冲突爆发：比如“入门考核遭遇暗箱操作，主角面临被淘汰的风险”）；④ 合（卷末收尾：达成卷的核心目标，留下下一卷的伏笔，比如“主角成功入门，但发现门派长老对自己的身世格外关注，埋下悬念”）。
    
- 卷内人设适配（明确核心人设在这一卷的表现的重点：比如主角“隐忍善良”，在这一卷重点体现“遭遇刁难时不冲动，却在伙伴被欺负时挺身而出”；反派“伪善狡诈”，重点体现“表面是和蔼的门派师兄，暗地里给主角使绊子”），避免人设崩塌。
    

## 二、章组划分（将卷内节点拆解为可落地的章群）

卷内关键剧情节点还是偏“粗”，需要进一步拆分成「章组」——即围绕一个小目标/小冲突，由若干章节组成的“剧情模块”。章组的划分能避免单章内容杂乱，确保每一章都有明确的归属和目标，同时控制单章的篇幅和节奏。

具体产出内容：

- 章组主题（每个章组对应一个小目标，比如“章组1：离开家乡与初遇危机”“章组2：入门考核与竞争对手交锋”）。
    
- 章组包含的章节数量（根据剧情复杂度定，通常1个章组对应2-5章，比如“章组1：第1-3章”，分别写“主角告别家乡”“途中遇山贼”“侥幸脱身”）。
    
- 章组的核心冲突/目标（明确这个章组要解决什么问题、展现什么内容，比如“章组1的核心：展现主角初入江湖的懵懂与无助，铺垫主角的成长动机，引入第一个剧情冲突”）。
    

示例：卷1粗大纲→卷1细化节点（4个）→章组划分（2个）：章组1（节点1+节点2）→第1-3章；章组2（节点3+节点4）→第4-7章。

## 三、单章核心框架（落地到每一章的具体指引）

章组划分完成后，就可以针对每一章，产出「单章核心框架」——这是AI写章内容的直接依据，明确每一章“写什么、怎么写、要达到什么效果”，避免AI写偏、写空。

具体产出内容（每一章都要写，简洁明了，适配AI创作）：

- 单章标题（可选，可先拟暂定标题，后续修改，比如“第1章：故土别，江湖始”“第2章：山道遇劫，绝境逢生”）。
    
- 单章核心目标（明确这一章的核心任务：是推进剧情、塑造人物、铺垫伏笔，还是渲染氛围？比如“第1章核心：交代主角的身世背景和离开家乡的原因，渲染离别氛围，埋下寻亲的伏笔”）。
    
- 单章关键场景（明确这一章的发生地点、时间，比如“场景：主角的家乡村口+前往江湖的山道，时间：清晨”）。
    
- 单章出场人物（明确这一章有哪些人出场，核心人物的行为逻辑的——结合人设，比如“出场人物：主角、主角母亲、山贼头目；主角行为：告别母亲时强装坚强，遇山贼时虽害怕但不退缩，符合‘隐忍善良’人设”）。
    
- 单章核心剧情（1-3个关键情节，按顺序排列，比如“第2章剧情：1. 主角走在山道，察觉有人跟踪；2. 山贼头目带人拦截，索要钱财；3. 主角凭借母亲给的护身符，暂时脱身，但护身符受损”）。
    
- 单章细节要求（可选，重点标注需要AI突出的内容：比如“突出主角的心理活动——离开家乡的不舍、遇劫时的恐惧与倔强；突出山贼头目的凶狠，为后续伙伴登场做铺垫”）。
    
- 单章收尾（明确这一章的结尾的方式：是留下小悬念、推进到下一个剧情，还是完成一个小目标？比如“第2章结尾：主角脱身後，发现山道前方有一个身影，不知是敌是友，留下悬念”）。
    

## 四、补充辅助内容（可选，但能大幅提升AI创作质量）

如果希望AI写的内容更贴合你的预期，避免人设跑偏、剧情逻辑漏洞，还可以补充以下内容，作为上述框架的辅助：

1. 人设细化补充（核心人设之外，补充「人物行为细节、语言风格、心理偏好」，比如“主角说话语速偏慢，不擅长表达情绪，生气时会攥紧拳头；伙伴说话直来直去，喜欢调侃主角，但关键时刻很可靠”，AI能更精准地塑造人物对话和行为）。
    
2. 世界观补充（如果小说有特定世界观，比如江湖门派、奇幻设定、时代背景，补充卷内相关的世界观细节，比如“门派入门考核的规则、江湖中山贼的常见出没地点、主角护身符的特殊作用”，避免AI写出不符合世界观的内容）。
    
3. 伏笔与回收清单（梳理卷内要埋下的伏笔、以及伏笔的回收节点，比如“第1章埋下‘主角护身符是寻亲关键’的伏笔，第7章（卷末）回收，让长老看到护身符后产生异常反应”，确保剧情连贯）。
    
4. 节奏把控说明（明确每一章的节奏：比如“前3章节奏偏缓，侧重铺垫和人物引入；第4-5章节奏加快，侧重冲突爆发；第6-7章节奏放缓，侧重收尾和伏笔铺垫”，避免AI写的内容节奏混乱）。
    

## 总结（落地逻辑）

核心逻辑：卷级粗大纲 → 卷级细化大纲（关键节点+起承转合+人设适配） → 章组划分（剧情模块） → 单章核心框架（每章具体指引） → 辅助补充内容（人设/世界观/伏笔）。

其中，「卷级细化大纲」和「单章核心框架」是最关键的两个环节——前者确保不偏离粗大纲和人设，后者直接落地到每一章的内容，AI只需按照单章框架填充细节、优化语言，就能产出符合预期的章节内容，同时避免写崩、写偏。
