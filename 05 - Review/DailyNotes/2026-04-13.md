### 链表分解
- 初认识：修改「原链表」，逐个比较并移动链表元素
- 难点：
	- 无法确定移动规律，还需要保证移动后元素间初始相对位置一致
- 破局点：
	- 新增>修改：原链表分解成2个新子链表，一个记录小于X的元素，一个记录大于X的元素；再实现拼接
- 坑点：
	- 链表一分为2，需要保证原链表元素之间联系要断开。
- 模板代码：
- ```java
  public ListNode partition(ListNode head){
	  ListNode d1=new ListNode(-1);
	  ListNode d2=new ListNode(-1);
	  
	  ListNode p=head;
	  ListNode p1=d1;
	  ListNode p2=d2;
	  
	  while(p!=null){
		  //小于x由d1链表记录
		  if(p.val<x){
			  p1.next=p;
			  p1=p1.next;
		  }
		  else{
		  //大于X由d2链表记录
			  p2.next=p;
			  p2=p2.next;
		  }
		  //断开原链表元素之间的联系
		  ListNode temp=p.next;
		  p.next=null;
		  p=temp;
	  }
	  //链接2个链表
	  p1.next=d2.next;
	  return d1.next;
  }
  ```

### 合并N个有序链表
- 难点：如何快速从各个链表当前节点中找到最小的元素（O(M`*`N)）
- 破局点：最小堆查找（O(M`*`logN)）
- 代码模板
- ```java
  public ListNode mergeNList(ListNode[] list){
	  ListNode dummy1=new ListNode(-1);
	  ListNode p=dummy1;
	  //priority queue
	  PriorityQueue<ListNode> pq=new PriorityQueue<>(list.length,(a,b)->(a.val-b.val));
	  for(int i=0;i<list.length;i++){
		  if(list[i]!=null)
			  pq.add(list[i]);
	  }
	  
	  while(!pq.isEmpty()){
		  ListNode curNode=pq.poll();
		  if(curNode==null) continue;
		  p.next=curNode;
		  p=p.next;
		  if(curNode.next!=null){
			  pq.add(curNode.next);
		  }
	  }
	  
	  return dummy1.next;
  }
  ```

###  单链表的倒数第K个节点
- 初认识：遍历2次，第一次获取链表长度n，第二次倒数第K个节点等于顺数第`n-k+1`个节点
- 难点：一次遍历得结果；需要找规律取巧。
- 破局点：
	- 让A指针走`k`步
	- 让B和A指针同时走，当A走到链尾时，B指针指向的位置即为第`n-k+1`个节点（A=B=n-k步）
