### 二叉树——分解类型：

#### 从前序和中序遍历中构造二叉树
- 分析
	- 目标：构建二叉树
	- 剖析：二叉树构成=root+左子树+右子树 =>自下往上=>分解子问题类型
	- 更小同构问题：左子树 & 右子树 `构造递归条件+调用递归方法`
	- X元素：root根节点
	- 子问题与X元素如何得出原问题答案：
		-  构建root根节点
		- 构建左子树：
			- preorder：头索引+1、+元素个数
			- inorder：头索引，根索引-1
		- 构建右子树：
			- preorder：+元素个数+1、尾索引
			- inorder：根索引+1、尾索引
- 核心代码：
- ```java
        Map<Integer, Integer> inOrderIdxMap = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {

        for (int i = 0; i < inorder.length; i++) {
            inOrderIdxMap.put(inorder[i], i);
        }

        TreeNode root = build(preorder, 0, preorder.length - 1, inorder, 0, inorder.length - 1);

        return root;
    }

    public TreeNode build(int[] preOrder, int pStart, int pEnd, int[] inOrder, int iStart, int iEnd) {

        //基准条件：最小子问题
        if (pStart > pEnd) {
            return null;
        }

        //得到root值
        int rootVal = preOrder[pStart];
        //得到rootVal在inOrder数组中的位置
        int rootIdx = inOrderIdxMap.get(rootVal);

        //根节点构造
        TreeNode root = new TreeNode(rootVal);
        //构造左右子树
        //递归实现条件： 
        //inOrder左子树元素= inOrder中 root索引左边的数组；inOrder右子树=inOrder中 root索引右边的数组；
        //preOrder左子树元素= 根节点后第一个索引出发+左子树元素个数； preOrder右子树元素= 左子树preOrder最后一个元素索引后出发至数组尾端

        int leftSize = rootIdx - iStart;

        root.left = build(preOrder, pStart + 1, pStart + leftSize, inOrder, iStart, rootIdx - 1);
        root.right = build(preOrder, pStart + leftSize + 1, pEnd, inOrder, rootIdx + 1, iEnd);

        return root;
    }
  ```
