### 链表专题
#### 单链表的中点（中间有2个节点，选第二个）
- 初认识：先遍历一次获取链表长度n，中间节点=n/2+1
- 难点：一次遍历得到链表中点
- 破局点：快慢指针同时走，慢指针每次走一步，快指针每次走两步，当快指针到尽头(null)时，慢指针指向的地方即为链表中点
- 模板代码；
- ```java
  public void findMidNode(ListNode head){
	  ListNode slow=head;
	  ListNode fast=head;
	  while(fast!=null&&fast.next!=null){
		  slow=slow.next;
		  fast=fast.next.next;
	  }
	  
	  return slow;
  }
  ```

#### 两个链表是否相交
- 初认识：链表相交=链表节点相等；同时遍历链表，链表节点相等时则表示相交，当链表结尾后仍无相同节点，则无相交
- 难点：链表长度不一，齐头并进遍历会让相交的节点无法对应。
- 破局点：
	- 将链表B尾与链表A头相连，将相交问题转化为`成环问题`。
	- 找到环入口后，slow（从链头出发）和fast同时遍历，再次相遇时即为`相交点`；
	- ```bash
	  //推导过程
	  1. 起点 → 环入口：长度 a
	  2. 环入口 → 相遇点：长度 b
	  3. 相遇点 → 环入口：长度 c
	  4. 整个环一圈长度：L = b + c
	  
	  快慢指针第一次相遇:
	  慢指针走了：a + b
	  快指针走了：a + b + nL（多绕了 n 圈）
	  快指针速度是慢指针 2 倍
	  
	  2(a + b) = a + b + nL
	  环长 L = b + c
	  a = n(b + c) - b
	  当 n=1(步长)
	  a = c
	  ```
	- 记得将节点还原
- 模板代码：
- ```java
  public ListNode getIntersectionNode(ListNode headA,ListNode headB){
	  if(headA==null||headB==null)
		  return null;
		  
	  ListNode p=headB;
	  while(p.next!=null){
		  p=p.next;
	  }
	  
	  //链表B尾与链表A头相连
	  p.next=headA;
	  //判断成环
	  ListNode slow=headB;
	  ListNode fast=headB;
	  boolean flag=false;
	  
	  while(fast!=null&&fast.next!=null){
		  slow=slow.next;
		  fast=fast.next.next;
		  
		  if(slow==fast){
			  flag=true;
			  break;
		  }
	  }
	  //不相交
	  if(!flag) return null;
	  
	  //相交后找成环点
	  slow=headB;
	  while(slow!=fast){
		  slow=slow.next;
		  fast=fast.next;
	  }
	  
	  //还原链表连接
	  p.next=null;
	  
	  return slow;
  }
  ```
