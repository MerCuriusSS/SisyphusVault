- 初想法：链表只能单向移动，所以反转链表到新的链表，判断新旧链表是否一致实现回文判断
- 核心代码：
- ```java
  public boolean judgeHuiWen(ListNode head){
	  if(head==null||head.next==null)
		  return true;
	  ListNode pre=null;
	  ListNode cur=head;
	  ListNode nxt=head.next;
	  while(cur!=null){
		  ListNode nNode=new ListNode(cur.val);
		  nNode.next=pre;
		  pre=nNode;
		  cur=nxt;
		  if(nxt!=null){
			  nxt=nxt.next;
		  }
	  }
	  
	  //pre为新链表的头节点
	  //head为旧链表头节点
	  ListNode p=head;
	  ListNode p2=pre;
	  while(p!=null){
		  if(p.val!=p2.val){
			  return false;
		  }
		  p=p.next;
		  p2=p2.next;
	  }
	  
	  return true;
  }
  ```
