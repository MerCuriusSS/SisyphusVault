## 9:30-16:30（算法）
一、合并两个有序链表
- 初想法：
	- 以链表A作为基准，把链表B的节点插入到A中；
	- 插入一个节点需要同时关注**前驱节点**和**后继节点**，指针操作复杂。
	- 推进不下去，失败告终。
- 问题点：
	- 缺乏“结果反推输入”的思维，只盯着“输入链表要怎么改”，而不是想着“我最终要得到什么”
	- 缺乏对每个推导前提的质疑——是否一定需要修改原链表？思维路径：
		- `if`以链表A为基准，那么链表B往A中插入元素
			- `if headB>headA
				- `if headA.next > headB`,可插入;
				- `if headA.next < headB`,不可插;
			- ...
- 解题思路：
	- 以新虚拟节点（dummyNode）为基准，每次比较A，B两个链表的值，将较小的节点链入虚拟节点中，并推进小的链表进度。
	- 某个链表推进完全后，新链连接剩下的链表。
	- 涉及到`增`操作，使用`虚拟节点`减少边界条件。
	- 核心代码：
	- ```java
	  public ListNode mergeList(ListNode l1,ListNode l2){
	  	  ListNode dummy=new ListNode(null);
		  ListNode head=dummy;
		  ListNode p1=l1;
		  ListNode p2=l2;
		  while(pA!=null&&pB!=null){
			  if(pA.val<pB.val){
				  dummy.next=pA;
				  pA=pA.next;
			  }else{
				  dummy.next=pB;
				  pB=pB.next;
			  }
			  dummy=dummy.next;
		  }
		  if(pA!=null)
			  dummy.next=pA;
		  if(pB!=null)
			  dummy.next=pB;
		  return head.next;
	  }

	  ```
二、反转链表
- 初想法：
	- 从「头」开始反转（「尾」需要额外遍历一次）
	- 怎么反转？（null->A->B->C->D）
		- 反转后指针变化，需记录翻转原节点的next节点。
		- 反转A，将B.next指向A
- 卡壳点：把A当成反转后的尾节点（实际上也不是），把B当成反转后链表的头节点，所以初始化混乱：cur=A;next=B;next2=B.next;
- 破局点：反转链表的结果是以**当前节点为链头**。故反转A不是让B.next指向A，而是让A.next指向前
- 核心代码：
- ```java
 public ListNode reverseList(ListNode head){
	 if(head==null||head.next==null)
		 return head;
	 ListNode cur=head;
	 ListNode pre=null;
	 ListNode next=cur.head;
	 while(cur!=null){
		 cur.next=pre;
		 pre=cur;
		 cur=next;
		 if(next!=null){
			 next=next.next;
		 }
	 }
	 
	 return cur;
 }
  ```
