## 一、链表专题

### 1. 合并两个有序链表

记录日期：2026-03-30、2026-03-31

初始问题：

- 最开始倾向于以链表 A 为基准，把链表 B 的节点插入 A。
- 插入过程需要同时维护前驱节点和后继节点，指针操作复杂。
- 思维重点放在“如何修改输入链表”，而不是“最终需要构造什么结果”。

破局思路：

- 使用虚拟头节点 `dummyNode`。
- 每次比较两个链表当前节点，选择较小节点接到结果链表后。
- 某个链表走完后，直接连接另一个链表剩余部分。

沉淀原则：

- 涉及链表新增、拼接、合并时，优先考虑虚拟头节点。
- 修正“链表操作要原地修改”的定式思维，结果链表思维更稳定。

核心模板：

```java
public ListNode mergeList(ListNode l1, ListNode l2) {
    ListNode p1 = l1;
    ListNode p2 = l2;
    ListNode dummy = new ListNode(-1);
    ListNode p = dummy;

    while (p1 != null && p2 != null) {
        if (p1.val < p2.val) {
            p.next = p1;
            p1 = p1.next;
        } else {
            p.next = p2;
            p2 = p2.next;
        }
        p = p.next;
    }

    if (p1 != null) {
        p.next = p1;
    }
    if (p2 != null) {
        p.next = p2;
    }

    return dummy.next;
}
```

### 2. 反转链表

记录日期：2026-03-30、2026-03-31、2026-04-16

初始问题：（null->A->B->C->D）

- 容易把反转理解成“让后一个节点指向前一个节点”。
- 初始化时会混淆 `cur`、`pre`、`next` 的含义。
- 最开始把 A 当成反转后的尾节点，把 B 当成反转后的头节点，导致推导混乱。

破局思路：

- 反转链表的本质是：让当前节点成为已反转链表的新头节点。
- 每轮操作分三步：先保存后继，再指向前驱，再整体后移。

核心模板：

```java
public ListNode reverseList(ListNode head) {
    ListNode pre = null;
    ListNode cur = head;

    while (cur != null) {
        ListNode next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }

    return pre;
}
```

递归反转思路：

- 将原问题拆解成更小子问题：反转 `head.next` 之后的链表。
- 当前节点 `head` 接到反转后链表的尾部。
- 最小子问题是空链表或单节点链表。

递归模板：

```java
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode last = reverseList(head.next);
    head.next.next = head;
    head.next = null;
    return last;
}
```

### 3. 环形链表判断

记录日期：2026-03-31、2026-04-01

初始问题：

- 曾尝试固定一个指针在头节点，另一个指针移动，误以为成环必定相遇。
- 问题在于成环点不一定是头节点。
- 快慢指针初始化时没有站在同一起跑线。
- 循环条件没有保证 `fast` 和 `slow` 同步推进。

破局思路：

- 使用快慢指针。
- `slow` 每次走一步，`fast` 每次走两步。
- 如果有环，二者必定相遇。
- 如果 `fast` 或 `fast.next` 为 null，则无环。

核心模板：

```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;

        if (slow == fast) {
            return true;
        }
    }

    return false;
}
```

关键避坑：

- 快慢指针必须同一起点。
- `while` 条件必须检查 `fast != null && fast.next != null`。
- 成环点不等于头节点。

### 4. 链表分解

记录日期：2026-04-13

题型目标：

- 将原链表按阈值 `x` 分解成两个链表。
- 小于 `x` 的节点在前，大于等于 `x` 的节点在后。
- 保持原始相对顺序。

初始问题：

- 试图直接修改原链表，逐个比较并移动节点。
- 难点在于移动后仍要保证元素原始相对位置。

破局思路：

- 原链表拆成两个新链表。
- 一个保存小于 `x` 的节点。
- 一个保存大于等于 `x` 的节点。
- 最后拼接两个链表。

关键避坑：

- 每次移动节点后，要断开原链表中的旧连接，避免形成错误链路。

核心模板：

```java
public ListNode partition(ListNode head, int x) {
    ListNode d1 = new ListNode(-1);
    ListNode d2 = new ListNode(-1);
    ListNode p1 = d1;
    ListNode p2 = d2;
    ListNode p = head;

    while (p != null) {
        if (p.val < x) {
            p1.next = p;
            p1 = p1.next;
        } else {
            p2.next = p;
            p2 = p2.next;
        }

        ListNode temp = p.next;
        p.next = null;
        p = temp;
    }

    p1.next = d2.next;
    return d1.next;
}
```

### 5. 合并 N 个有序链表

记录日期：2026-04-13

难点：

- 如何快速从 N 个链表的当前节点中找到最小节点。
- 暴力扫描复杂度高，约为 `O(M * N)`。

破局思路：

- 使用最小堆。
- 每次从堆中取出当前最小节点。
- 如果该节点还有后继节点，则把后继节点加入堆。
- 复杂度优化为 `O(M * logN)`。

核心模板：

```java
public ListNode mergeKLists(ListNode[] lists) {
    ListNode dummy = new ListNode(-1);
    ListNode p = dummy;

    PriorityQueue<ListNode> pq = new PriorityQueue<>(
        lists.length,
        (a, b) -> a.val - b.val
    );

    for (ListNode node : lists) {
        if (node != null) {
            pq.offer(node);
        }
    }

    while (!pq.isEmpty()) {
        ListNode cur = pq.poll();
        p.next = cur;
        p = p.next;

        if (cur.next != null) {
            pq.offer(cur.next);
        }
    }

    return dummy.next;
}
```

### 6. 单链表倒数第 K 个节点

记录日期：2026-04-13

初始思路：

- 遍历两次。
- 第一次获取链表长度 `n`。
- 第二次找第 `n - k + 1` 个节点。

破局思路：

- 使用双指针。
- 快指针先走 `k` 步。
- 快慢指针同时走。
- 当快指针走到链尾时，慢指针就是倒数第 K 个节点。

核心模型：

```java
public ListNode findKthFromEnd(ListNode head, int k) {
    ListNode fast = head;
    ListNode slow = head;

    for (int i = 0; i < k; i++) {
        fast = fast.next;
    }

    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }

    return slow;
}
```

### 7. 单链表中点

记录日期：2026-04-14

题型目标：

- 找链表中点。
- 如果中间有两个节点，选择第二个。

破局思路：

- 快慢指针。
- `slow` 每次走一步。
- `fast` 每次走两步。
- `fast` 到达链尾时，`slow` 指向中点。

模板：

```java
public ListNode middleNode(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    return slow;
}
```

### 8. 两个链表是否相交

记录日期：2026-04-14

初始问题：

- 想同时遍历两个链表，发现链表长度不一致时，相交节点无法对齐。

记录中的破局思路：

- 将链表 B 尾部连接到链表 A 头部。
- 把相交问题转化为成环问题。
- 找到环入口，即为相交点。
- 最后必须还原链表。

注意：

- 这种方法可以作为转化思维训练。
- 面试中更推荐“双指针换头法”，因为不需要修改链表结构。

推荐模板：

```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode p1 = headA;
    ListNode p2 = headB;

    while (p1 != p2) {
        p1 = p1 == null ? headB : p1.next;
        p2 = p2 == null ? headA : p2.next;
    }

    return p1;
}
```

### 9. 部分反转链表

记录日期：2026-04-20

题型：

- 反转链表中 `[n, m]` 区间的元素。

初始问题：

- 想一把梭直接处理整个原链表。
- 对反转链表后 `cur` 自动指向下一个节点的特征掌握不熟。

破局思路：

- 将“反转前 N 个节点”封装成可复用函数。
- 区间反转时，先找到第 `n - 1` 个节点。
- 对 `pre.next` 开始的 `m - n + 1` 个节点执行反转。

关键意识：

- 链表复杂题要主动复用基础反转模板。
- 不要每道题都重新手写一套指针逻辑。

### 10. 回文链表

记录日期：2026-04-21

初始思路：

- 链表只能单向移动，所以复制并反转一条新链表，再与原链表逐个比较。

进一步思路：

- 利用递归后序遍历的“逆序访问”特点，模拟左右双指针。

结论：

- 判断回文串是否成立：从两端往中间靠。
- 寻找回文串：从中间往两端扩展。

### 2. 层序遍历

记录日期：2026-04-09

核心思路：

- 使用队列保存当前待访问节点。
- 如果需要区分层级，每轮先记录当前队列大小 `size`。
- 一次处理 `size` 个节点，即当前层节点。

不区分层级模板：

```java
public void levelOrderTraverse(TreeNode root) {
    if (root == null) {
        return;
    }

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        TreeNode cur = queue.poll();
        System.out.println(cur.val);

        if (cur.left != null) {
            queue.offer(cur.left);
        }
        if (cur.right != null) {
            queue.offer(cur.right);
        }
    }
}
```

区分层级模板：

```java
public void levelOrderByLevel(TreeNode root) {
    if (root == null) {
        return;
    }

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();

        for (int i = 0; i < size; i++) {
            TreeNode cur = queue.poll();
            System.out.println(cur.val);

            if (cur.left != null) {
                queue.offer(cur.left);
            }
            if (cur.right != null) {
                queue.offer(cur.right);
            }
        }
    }
}
```

### 3. 二叉树路径类问题

记录日期：2026-04-22

覆盖题型：

- 二叉树的所有路径
- 根节点到叶节点数字之和
- 从叶结点开始的最小字符串
- 从根到叶的二进制数之和

统一模型：

- 结果是从根到叶路径，属于自上往下的遍历型递归。
- 前序位置加入当前节点。
- 叶子节点位置收集答案。
- 后序位置撤销当前节点。

路径类模板：

```java
LinkedList<Integer> path = new LinkedList<>();
List<String> result = new ArrayList<>();

public void traverse(TreeNode root) {
    if (root == null) {
        return;
    }

    path.addLast(root.val);

    if (root.left == null && root.right == null) {
        result.add(pathToString(path));
    }

    traverse(root.left);
    traverse(root.right);

    path.removeLast();
}
```

关键收获：

- 遍历型递归要重视“现场恢复”。
- 如果在叶子节点做了特殊操作，例如字符串反转，要在同一层恢复，避免后序阶段重复影响所有返回路径。

### 4. 构造二叉树

记录日期：2026-04-23、2026-04-24

覆盖题型：

- 从前序和中序遍历构造二叉树
- 从中序和后序遍历构造二叉树

统一模型：

- 构造二叉树属于分解型递归。
- 原问题 = 构造根节点 + 构造左子树 + 构造右子树。
- 中序数组用于确定左右子树边界。
- 前序数组首元素或后序数组尾元素用于确定根节点。
- 使用 HashMap 保存中序值到索引的映射，避免重复查找。

前序 + 中序核心关系：

- `preorder[pStart]` 是根节点。
- 根节点在中序数组中的左侧是左子树。
- 根节点在中序数组中的右侧是右子树。
- 左子树长度为 `rootIndex - iStart`。

中序 + 后序核心关系：

- `postorder[postEnd]` 是根节点。
- 根节点在中序数组中的左侧是左子树。
- 根节点在中序数组中的右侧是右子树。
- 左子树长度为 `rootIndex - inStart`。

## 三、递归思维

记录日期：2026-04-16、2026-04-22

### 1. 递归问题分类

递归题先判断结果类型：

- 自上往下：遍历型递归
- 自下往上：分解型递归

遍历型递归：

- 问题拆解为“遍历更小结构”。
- 重点是路径、状态、选择、撤销。
- 常见于路径收集、树遍历、回溯。

分解型递归：

- 问题拆解为“子问题返回值 + 当前元素如何组合”。
- 重点是递归函数定义和返回值。
- 常见于构造树、反转链表、求树高、判断平衡树等。

### 2. 递归通用方法论

递归分析步骤：

1. 明确递归函数定义。
2. 判断是遍历型还是分解型。
3. 找到最小子问题或边界条件。
4. 分析当前节点与子问题之间的关系。
5. 写出递归调用。
6. 确认是否需要撤销现场。

## 四、回溯专题

记录日期：2026-04-24、2026-04-25

### 1. DFS 与回溯的区别

共同点：

- 本质上都是递归遍历。

DFS 特点：

- 节点已知。
- 元素之间有明确上下级关系。
- 添加和移除节点操作通常发生在当前节点。

回溯特点：

- 选项构成树枝，结果构成节点。
- 节点是待选出来的。
- 元素之间通常是平级集合关系。
- 操作模式是做选择、递归、撤销选择。

回溯模板：

```java
void backtrack(Path path, Choices choices) {
    if (满足结束条件) {
        result.add(path);
        return;
    }

    for (Choice choice : choices) {
        if (!isValid(choice)) {
            continue;
        }

        做选择;
        backtrack(path, choices);
        撤销选择;
    }
}
```

### 2. 数独问题

记录日期：2026-04-24

前置技巧：

- 二维数组映射一维：`index = i * n + j`
- 从一维恢复二维：
  - `r = index / 9`
  - `c = index % 9`
- 小九宫格检查：
  - 行：`(r / 3) * 3 + i / 3`
  - 列：`(c / 3) * 3 + i % 3`

约束条件：

- 行不能重复。
- 列不能重复。
- 小九宫格不能重复。
- 已有数字跳过。
- 找到一个可行解后停止继续搜索。
